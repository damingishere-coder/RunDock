# Alter 项目化分类与可靠启停执行任务

## 背景

Alter 当前以单个受管进程为展示和操作单位，`namespace` 同时承担技术分组与界面分组职责。前后端项目因此被拆成多行，未指定命名空间的进程落入 `default`。现有手动停止还可能与自动重启事件竞态，前端又静默吞掉操作错误，造成按钮像失灵一样。

## 目标

- 建立“分类 → 项目 → 技术组件”三层模型，主页面和活动侧栏只显示项目。
- 新增可编辑的项目显示名称、备注和分类，且不修改底层进程名称。
- 提供项目级启动、停止、重启和启停用接口。
- 修复手动停止后被旧自动重启事件重新拉起的问题，并向界面返回真实错误。
- 将现有 12 条进程归并为 8 个项目；QQ Study 与知乎工作台进入“待定”、停止并停用。
- 构建、备份并升级本机 Alter，可失败回滚。

## 允许修改范围

- `src/config`、`src/models`、`src/process`、`src/daemon`、`src/api` 中与项目模型、持久化和生命周期相关的代码。
- `web-ui/src` 中项目列表、项目详情、活动侧栏、API 与类型代码。
- 与本功能直接相关的 Rust/前端测试、API 文档和本任务文件。
- 构建生成目录、测试缓存，以及经用户批准安装的官方 Rust GNU 工具链。
- 经验证后的 `%APPDATA%/alter-pm2` 项目元数据和进程状态，以及备份后的本机 `alter.exe` 替换。

## 禁止修改范围

- 不回退、覆盖或格式化与本任务无关的现有未提交改动。
- 不修改各业务项目的生产源码、数据库或 secrets；不读取/输出 `.env` 内容。
- 不改底层进程真实名称、日志目录、CLI 名称解析和既有 namespace 语义。
- 不 Git commit、push、重写历史、发布远程版本或执行生产部署。
- 不安装 Visual Studio/MSVC 等大型组件；GNU 工具链不足时暂停并报告。
- 不停止“常用”项目；除已确认属于 QQ Study/知乎的进程外，不终止来源不明的进程。

## 已确定实现要求

- `project_id` 是稳定内部标识；旧记录缺失时使用进程 ID 作为兼容项目 ID。
- 项目元数据单独原子化持久化：`display_name`、`note`、`category`；显示名称与备注更新不得重启组件。
- 分类默认“常用”，排序时“常用”优先、“待定”最后；项目界面不展示 `default`。
- 项目状态包含运行中、部分运行、已停止、异常、已停用；资源用量聚合。
- 项目级操作返回每个组件的成功或失败结果；界面显示加载、成功和错误反馈。
- 手动停止先写入期望停止状态；旧退出/自动重启/文件监视事件必须被忽略。
- Windows 进程树停止必须检查 `taskkill` 结果并确认 PID 消失，失败时不得伪装为已停止。
- 主页面和活动侧栏按项目显示；技术组件仅在项目详情展开。
- QQ Study（Web、Bridge）和知乎工作台（Backend、Frontend）迁入“待定”，停止并停用；其他六个项目进入“常用”并保持原运行状态。

## 验收标准

- 项目接口完整且旧进程接口保持兼容。
- 主页面显示 8 个项目，不显示 `default`，知乎只显示一个项目行。
- 活动侧栏按项目计数，不再显示前后端/Bridge 为独立活动项。
- 名称和备注修改后刷新、重启守护进程仍保留，底层 `name` 与日志路径不变。
- QQ Study/知乎分类为“待定”、`enabled=false`、相关端口不再监听。
- 手动停止的可自动重启进程在等待超过重启延迟后仍保持停止。
- API/UI 对停止失败显示明确错误。
- 新二进制失败时能恢复旧二进制和原状态。

## 测试命令

- `npm test -- --run`（`web-ui`）
- `npm run lint`（`web-ui`）
- `npm run build`（`web-ui`）
- `cargo fmt --check`
- `cargo clippy --all-targets -- -D warnings`
- `cargo test --all-targets`
- `cargo build --release --target x86_64-pc-windows-gnu`
- 本机 API、UI、进程状态、端口和重启持久化烟雾测试。

## 返回格式

- 修改文件和关键行为摘要。
- 实际执行的测试命令、通过数量和失败证据。
- 安装/备份/回滚位置与本机升级结果。
- 当前 8 个项目的分类、状态和启用状态。
- 未解决风险或后续事项；不得包含任何密钥或环境变量值。
